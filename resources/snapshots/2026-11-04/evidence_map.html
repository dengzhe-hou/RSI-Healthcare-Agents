Controller, self-evolver, configuration templates and versioned rules; v0.3.25 package reports128 passing unit/regression tests.
Update generator
Self-evolver generates versioned rule changes under a fixed protocol; detailed implementation of its proposal procedure is not reported.
Selection and release
Change record requires frozen trigger evidence, root-cause account, proposed rule, adjudication, successor version, rollback target, regression result and independent-evaluation boundary.
Evaluation separate from updating
300 virtual-EHR tasks in11 first-pass stages; controller versions change across stages. Only named same-stage retests support version contrasts; no separate held-out learning-transfer test.
Fixed-procedure control
Named predecessor/successor controller runs, without a matched frozen-improver control; aggregate across versions is explicitly descriptive.
Evidence concerning improver change
The external controller changes task action admission. No revision and later-learning test of the change-proposal/adjudication procedure itself is demonstrated.
Clinical setting
Virtual-EHR task execution with FHIR-oriented tools, including medication and service writes.
Evidence boundary
Single-creator preprint; same-stage retests, missing scorer outcomes and candidate governance labels are disclosed. Version changes across different stages do not isolate causal gains; no clinical care was delivered.
