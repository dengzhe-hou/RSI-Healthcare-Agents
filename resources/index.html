Use the map in your work

Start with the coding guide, inspect a coded example, and retain the study key, examined version and source locators in any extension. A standard-library Python example reads CSV/JSON, filters update targets and prints original source references. The guide applies existing RSI concepts to healthcare evidence; conceptual and primary sources should receive their own attribution.
